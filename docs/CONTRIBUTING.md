# Contributing

Thank you for your interest in Refugee Navigator Europe.

The project is in initial development. Application functionality has not yet been implemented.

- Open an issue to discuss proposed functionality or significant changes.
- Keep pull requests small, focused, and clearly described.
- Follow `.editorconfig` and existing C# conventions.
- Add relevant tests when introducing behavior.
- Run the restore, Release build, and test commands in the README before submitting a pull request.
- Never commit secrets, personal information, local configuration, or build artifacts.
- When country information is introduced, cite authoritative sources and identify when it was checked.
