# Внутренняя заметка наблюдателя

Не записывайте имя, контактные данные, пароль, иммиграционный статус или иные чувствительные сведения. Используйте номер сценария, а не личные сведения участника.

- **Дата / номер сессии:**
- **Сценарий:** № ___ / другое: ___
- **Результат:** завершено / частично / не завершено
- **Где возникла трудность:**
- **Что сказал или сделал участник (без идентифицирующих деталей):**
- **Повторение проблемы:** шаги, необходимые для воспроизведения
- **Предполагаемая серьёзность:** Critical / Major / Minor / Suggestion
- **Предлагаемое продолжение:**

## Шкала серьёзности

- **Critical** — блокирует использование или создаёт серьёзный риск для безопасности/достоверности.
- **Major** — важная задача не выполняется или большинство пользователей, вероятно, застрянет.
- **Minor** — заметное неудобство с понятным обходным путём.
- **Suggestion** — идея улучшения без текущей блокирующей проблемы.

Фиксируйте наблюдение отдельно от интерпретации. Пустая категория без статьи — ожидаемое состояние; запишите её как проблему только если сообщение вводит пользователя в заблуждение или отображается неправильно.
