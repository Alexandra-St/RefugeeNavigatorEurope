## Severity definitions

- **Critical:** Blocks access or use, or creates a serious security or legal-understanding risk.
- **Major:** An important user task fails, or a misleading interpretation is likely.
- **Minor:** A meaningful inconvenience exists, but a workaround is available.
- **Suggestion:** A non-blocking improvement idea.

Keep observation separate from interpretation. Do not include credentials, personal identifiers, document numbers, or immigration histories.
